## Breaking changes

**Strict semver answer**: removal of three public modules → minor bump. **Practical impact**: zero for any consumer outside the test suite.

Removed:
- `nwt_substrate.electroweak.heavy_meson_decay_constants`
- `nwt_substrate.electroweak.light_meson_decay_constants`
- `nwt_substrate.electroweak.vector_meson_decay_constants`

All consolidated into `nwt_substrate.particles.decay_constants`. The three deleted modules were dead code at the library import graph — only the now-deleted test files imported them; no known external consumer depended on them. Migration is a one-liner:

```python
# Before (v0.2.0)
from nwt_substrate.electroweak.heavy_meson_decay_constants import heavy_meson_fX_for
# After (v0.3.0)
from nwt_substrate.particles.decay_constants import heavy_meson_fX_for
```

The function signature and numerical output are unchanged.

The `_SubstrateNamespace` convenience bindings for meson decay constants are also removed from `nwt_substrate.electroweak.substrate` (`f_pi`, `heavy_meson_fX`, `vector_meson_fX`, etc.) — they would have created a circular import with `electroweak.substrate_gf`. Use the `particles.decay_constants` symbols directly.
